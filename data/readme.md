
# 📂 Datasets

This directory contains the datasets used for training and evaluating **Epi-UQ**. 

## 📥 Data Source

The raw benchmark datasets (including the IEDB-derived partitions and external cohorts) are originally curated and hosted by the **TransHLA** project. 
Please download the raw data files from the following official repository:

🔗 **[TransHLA Data Repository](https://github.com/SkywalkerLuke/TransHLA/tree/main/data)**

## 📝 Citation

We highly appreciate the contribution of the TransHLA team in curating these comprehensive immunoinformatics datasets. If you use these datasets in your research, please cite their original work:

> **[Tianchi Lu, Xueying Wang, Wan Nie, Miaozhe Huo, Shuaicheng Li, TransHLA: a Hybrid Transformer model for HLA-presented epitope detection, GigaScience, Volume 14, 2025, giaf008, https://doi.org/10.1093/gigascience/giaf008]**
